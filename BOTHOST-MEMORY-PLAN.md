## Поведение

Пн/Ср 20:00 Заря; Вт/Чт 18:30 Поле чудес; Сб/Вс 18:00 онлайн. Пятница без опроса. Публикация с 10:00 МСК, закрытие и удаление с 22:00, проверка каждые 15 секунд. После позднего запуска до 22:00 опрос публикуется сразу. При недоступности MAX удаление повторяется.

Две callback-кнопки, дата/место/время, Идут (N) и нумерованные имена. Обычный текст с emoji и inline keyboard, без обещания точных шрифтов/цветов MAX. Прикреплённый к предыдущему чату доступный скриншот показывает панель BotHost, а не оформление опроса: воспроизведена структура из требований.

Состояние только в Map/Set, без state.json, STATE_DIR, прав на каталог и Amvera initializer. Старые модули остаются для совместимости прежних тестов, но не входят в образ и не вызываются новым entrypoint. Production bot.js/config.js/service.js не изменены этой работой.

Дубли блокируются внутри одного процесса: резервирование до отправки, последовательная обработка, callback_id. Неопределённая отправка не повторяется. После рестарта информация теряется: старые callback игнорируются; возможна новая публикация в тот же день, а старое сообщение автоматически удалить уже нельзя. Между рестартами и несколькими экземплярами гарантировать отсутствие дублей без внешнего состояния невозможно. Запускать ровно один экземпляр.

Проверка /me (ID, username, is_bot), точного тестового чата и членства до старта HTTP. Отправка только в фиксированный тестовый чат; редактирование/удаление только ID, созданных текущим процессом. Токен BotHost принимается как alias, конфликт с TEST_BOT_TOKEN блокирует запуск. Все разрешения выключены по умолчанию.
