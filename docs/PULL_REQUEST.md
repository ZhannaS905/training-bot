Предназначен для draft PR и просмотра; Merge и выпуск не разрешены.

В исходном коде голоса хранились только в памяти и смешивались между чатами,
а старые кнопки меняли сегодняшний опрос. Новая реализация сохраняет опросы по chat_id/дате,
голоса по user_id и проверяет UUID и message ID. Кнопки позволяют изменить или отменить голос.
Публикация выполняется автоматически в 10:00 Europe/Moscow в дни тренировок,
либо вручную по /опрос только для ADMIN_IDS и разрешённых CHAT_IDS.

Удалены помощь, личные подтверждения, текстовые команды записи/отмены и устаревшие описания.
TLS включён; .env.example очищен; package.json/lock согласованы без внешних зависимостей.
Обновление опроса выполняется через PUT, без создания новых сообщений. logs/ сохранён побайтно.

Проверки: 11/11 тестов прошли, синтаксис и git diff --check без ошибок.
MAX API проверен по документации и фиктивным ответам; реальные API-вызовы не выполнялись.
Тесты открывали только локальный порт и временное хранилище, бот не запускался.

Перед выпуском обязательны: сверка реального состояния сервера (оно неизвестно),
испытание отдельного тестового бота/чата, настройка HTTPS Webhook и доверенных CA, Node.js >=22.
При неоднозначном результате отправки повтор блокируется до ручной сверки; возможен пропуск публикации.
Один процесс, локальный постоянный диск; после аварии блокировку снимает оператор после проверки.

Полные риски и план отката — docs/REFACTOR_REPORT.md. Старый рабочий SHA фиксируется отдельно;
при будущем разрешённом откате восстанавливается именно рабочая сборка, а не автоматически main.
