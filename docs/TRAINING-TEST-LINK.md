# Training Test: ссылка на онлайн-тренировку

В субботних и воскресных опросах отображается ровно одна строка:

```html
🔗 <a href="https://telemost.yandex.ru/j/35289250295816">Ссылка для подключения</a>
```

HTML-разметка сохраняется при отправке и последующих изменениях списка участников.
Очные опросы не изменены.

## Ограничения предпросмотра MAX (проверено 23 октября 2026)

- [POST /messages](https://dev.max.ru/docs-api/methods/POST/messages) поддерживает query-параметр `disable_link_preview=true`. Он передаётся при публикации онлайн-опроса Training Test, отдельно от JSON-тела.
- [PUT /messages](https://dev.max.ru/docs-api/methods/PUT/messages) не документирует параметр отключения превью. Редактирование продолжает использовать этот метод с HTML и обеими callback-кнопками; недокументированный параметр не добавлен.
- [POST /answers](https://dev.max.ru/docs-api/methods/POST/answers) поддерживает `disable_link_preview`, но требует callback_id. Он не заменяет существующее отложенное редактирование, которое также выполняется при повторных попытках без нового callback.

Таким образом, отключение предпросмотра запрошено при отправке. Гарантировать отсутствие карточки после редактирования через PUT технически нельзя по опубликованному API. Реальные сообщения не отправлялись и не редактировались: проверки выполняются с подставным транспортом. Деплой не выполнялся.
