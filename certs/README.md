# Публичный корневой CA для тестового подключения MAX

`russian-trusted-root-ca.pem` — публичный Russian Trusted Root CA, перенесённый
из ранее подготовленного и проверенного локального комплекта Training Test.
Закрытых ключей и токенов файл не содержит.

Первоначальный источник: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
Официальная страница сертификатов: https://www.gosuslugi.ru/crt

SHA-256-отпечаток сертификата:
`D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`

Профиль проверяет его перед запуском. Самоподпись сама по себе не подтверждает
источник сертификата; обновление файла и закреплённого отпечатка требует
отдельной сверки источника. Дополнительный CA не заменяет системные CA и не
отключает проверку имени хоста, цепочки или срока сертификата сервера MAX.
