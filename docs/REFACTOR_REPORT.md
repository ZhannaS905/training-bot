## Риски и обязательная приёмка

Новый транспорт Webhook и Node.js >=22 требуют отдельной настройки и испытания.
Это изменение способа доставки событий, а не готовое обновление существующего сервера.
Подписка/прокси не настраиваются автоматически. Проверить тайм-ауты, цепочку CA,
права в тестовом чате и актуальные формы callback событий на отдельном боте.
Опросы показывают количества голосов; имена не используются как идентификаторы.

Без idempotency key MAX нельзя одновременно гарантировать отсутствие пропуска и дубликата
при сбое между внешней отправкой и сохранением mid. Выбрана блокировка повтора с ручной сверкой.
При недоступности в 10:00 допускается публикация после восстановления до начала тренировки.
Большие очереди могут задерживать расписание, поскольку внешние вызовы последовательны.
Один процесс, локальный диск, ручное снятие аварийной блокировки. Нужны мониторинг размера состояния
и резервные копии. Старые голоса из оперативной памяти не мигрируются.
Потенциальный секрет удалён только из текущего шаблона; история Git не переписывалась,
действующий токен не менялся. Владельцу следует отдельно определить, был ли это реальный секрет.
